# 번역 필요 목록

CPP/H 파일(영어 주석 → 한글 주석) 번역 작업 기록입니다. 프로젝트(vcxproj) 단위로 진행하며,
각 프로젝트에서 실제로 컴파일되는 cpp와 그 cpp가 **직접** include하는 헤더를 우선 번역합니다.

## 1. CPP/H가 아닌 파일 (요청에 따라 이번에 번역하지 않음)

- basic/CMakeLists.txt — 영어 주석 다수
- basic/README.md — 영어 본문 다수
- Client/DXLib/CMakeLists.txt — 영어 주석 다수
- Client/DXLib/README.md — 영어 본문 다수

### basic 프로젝트 (basic.vcxproj) — 폴더 전체 CPP/H 완료

- basic/BasicData.h, basic/BasicData.cpp
- basic/timer2.h, basic/Timer2.cpp
- basic/BasicException.h, basic/BasicException.cpp

- basic/DLL.h, basic/i_signal.h, basic/IMG.h, basic/picinfo.h
- basic/PlatformUtil.h, basic/2d.h, basic/BasicMemory.h, basic/Typedef.h

### DXLib 프로젝트 (dxlib.vcxproj) — 컴파일 대상 cpp 8개 + 직접 include 헤더 7개

- Client/DXLib/CDirectDraw.cpp, Client/DXLib/CDirectDraw.h
- Client/DXLib/CDirectDrawSurface.cpp, Client/DXLib/CDirectDrawSurface.h
- Client/DXLib/CDirectSound.cpp, Client/DXLib/CDirectSound.h

- Client/DXLib/CDirectDraw_StaticMembers.cpp
- Client/DXLib/CDirectInput_Adapter.cpp, Client/DXLib/CDirectInput.h
- Client/DXLib/DXLibBackend.h

모두 UTF-8 with BOM으로 저장 확인함. 문자열 리터럴(오류 메시지 등)은 프로그램 출력이므로 번역 대상에서 제외함.

### TextSystem 프로젝트 (TextSystem.vcxproj) — 컴파일 대상 cpp 3개 + 직접 include 헤더 6개
- Client/TextSystem/TextService.cpp, Client/TextSystem/TextService.h
- Client/TextSystem/TextBackendSDL.cpp, Client/TextSystem/TextBackend.h
- Client/TextSystem/RenderTargetSpriteSurface.cpp, Client/TextSystem/RenderTargetSpriteSurface.h
- Client/TextSystem/FontHandleUtil.h
- Client/TextSystem/RenderTarget.h
- Client/TextSystem/TextTypes.h

모두 UTF-8 with BOM으로 저장 확인함. TextService.cpp, TextBackendSDL.cpp는 원래 CP949로
저장되어 있었고 일부는 이미 한글 주석이 번역돼 있었음(재번역 없이 유지) — 나머지 영어
주석만 한글로 번역하고 UTF-8 with BOM으로 재저장함(줄바꿈 CRLF 유지). 문자열 리터럴(오류
메시지 등)은 번역 대상에서 제외함. CPP/H 외 파일은 없어 자세한 내용은
`참고자료/작업지시/번역필요(TextSystem).md` 참고.
