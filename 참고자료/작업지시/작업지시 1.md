

# 목표

CMakeLists.txt를 수정하려고 해.

DarkEdenClient.sln 생성 시 Visual Studio 솔루션 탐색기 내부 프로젝트들을 USE_FOLDERS 속성을 활용해 아래 3개 솔루션 폴더로 분류하도록 변경해줘.

1) CMake 자동 생성 프로젝트 (ALL_BUILD, ZERO_CHECK 등)
   - 폴더명: "CMakeDefault"
   - set_property(GLOBAL PROPERTY PREDEFINED_TARGETS_FOLDER "CMakeDefault") 활용
2) 실행 파일 프로젝트 (.exe)
   - 폴더명: "exe"
3) 동적 라이브러리 프로젝트 (.dll)
   - 폴더명: "Core"

기존 add_executable 및 add_library 타겟에 set_target_properties(... PROPERTIES FOLDER ...) 설정이 올바르게 반영되도록 CMakeLists.txt 구성을 업데이트해줘.
